# Caption & Subtitle Styles for Finance YouTube Shorts (2025)

## Why Captions Matter

- Captioned videos earn +23% more likes and +24% more shares than uncaptioned versions
- Large portion of Shorts watched with sound off or low volume
- Caption style has become a brand identity signal in finance niche
- Word-by-word animated captions produce +15% engagement lift for finance/educational content

## 5 Caption Systems

### System 1: Hormozi Word-Highlight (Most Widely Adopted)

**Used by:** Alex Hormozi, Andrei Jikh, Graham Stephan, Minority Mindset, MeetKevin

| Parameter | Value |
|-----------|-------|
| Font | "The Bold Font" (Sven Pels), Montserrat Bold, Archivo Black |
| Color | White base + yellow keyword (#f7c204). Red for negative, green for positive |
| Animation | Word-by-word appearance, current word highlighted, previous words revert to white |
| Text density | 1-3 words per frame |
| Stroke | Heavy black 2-4px outline |
| Case | ALL CAPS |
| Size | 70-90px |
| Position | Lower-center (bottom 25%) |

**Signals:** Authority, energy, conviction. Red/green coding maps to stock market colors.

### System 2: Clean Minimalist (Trust-Building)

**Used by:** Humphrey Yang, Two Cents PBS, Swedish Investor, Economics Explained

| Parameter | Value |
|-----------|-------|
| Font | Poppins Regular/Medium, Open Sans, Roboto (lighter weight) |
| Color | White on semi-transparent dark background bar |
| Animation | Phrase-by-phrase (4-8 words together), fade transitions |
| Stroke | Minimal or none (background box provides contrast) |
| Case | Title case or sentence case |
| Size | 50-65px |
| Position | Center-screen (60-70% from top) |

**Background variants:**
1. Solid black rectangle at 70-80% opacity
2. No box, heavy drop shadow (blur 8-12px, 80% black opacity)

**Signals:** Credibility, clarity, intelligence.

### System 3: Animated Pop (High Energy)

**Used by:** Andrei Jikh (some content), Nick Invests (dialogue), viral trend content

| Parameter | Value |
|-----------|-------|
| Font | Multiple fonts swapped every 1-2 words (Impact + Montserrat, Bold Font + Bebas Neue) |
| Color | Multi-color rotation (yellow, red, white, cyan cycling) or gradient text |
| Animation | Per-word scale 110-120% on entry, horizontal slide-in alternating left/right |
| Effects | Outer glow 40-60% opacity, scale-bounce on emphasis, rotation +/-3 degrees |
| Text density | 1-2 words, often single word full-screen |
| Case | ALL CAPS |
| Position | Center-screen, large (80-100px) |

**Signals:** Entertainment, virality-signaling, hype. Best for hook sequences only (first 3-5 seconds).

### System 4: Animated Character Caption

**Used by:** Primate Economics, Monkey Economics, Nick Invests, Bob Invests, Crayon Capital

| Parameter | Value |
|-----------|-------|
| Font | Rounded sans-serif (Nunito, Quicksand) matching cartoon aesthetic |
| Color | Matches channel animation palette (banana yellow on dark green for Primate Economics) |
| Animation | Sentence-level with motion sync to character lip-sync |
| Text density | 6-10 words per unit |
| Position | Lower quarter OR upper third as title-style |
| Background | Semi-transparent box with rounded corners, color matches brand |

**Special technique (Primate Economics):** When monkey picks up banana as narrator says "inflation," the word "INFLATION" appears large in upper frame as a title-caption hybrid, not standard subtitle position.

### System 5: Kinetic Data Caption

**Used by:** Humphrey Yang (data Shorts), Economics Explained, Andrei Jikh (comparisons)

| Parameter | Value |
|-----------|-------|
| Font | Bold condensed for numbers (Barlow Condensed, Bebas Neue) + regular for labels (Poppins, Inter) |
| Color | Numbers in bright accent (yellow, cyan, orange). Negative in red. % signs enlarged |
| Animation | Number counter 0 → final value, bar graph text expanding horizontally |
| Text density | Data point + label only ("$47,000" + "invested at 25") |
| Position | Center-frame or upper-center for data; lower-third for narration |
| Background | Subtle gradient dark-to-transparent behind number, drop shadow, occasional glow |

**Signals:** Analytical authority. Number growing from zero mirrors emotional experience of watching wealth grow.

## Positioning Rules

| Position | When Used | Examples |
|----------|-----------|---------|
| Lower center (bottom 25-30%) | Voiceover narration, standard subtitle | Graham Stephan, MeetKevin |
| True center (45-55% from top) | Bold statement hooks, single-word emphasis | Alex Hormozi hooks |
| Upper third | Animated channels (center for characters) | Primate Economics, Nick Invests |
| Chin-level | Talking-head, mirrors natural reading gaze | Humphrey Yang, Codie Sanchez |

**Universal rule:** Captions must never cover character faces or key visual action. Eye contact is the retention anchor.

## Animation Timing Specs

### Word-by-word
- Each word appears on the accent syllable beat (not word start)
- Highlight crossfade: ~50ms (not instant)
- Word entry: 80-120ms scale-up from 80% to 100%
- Stay duration: matches spoken duration + 50ms buffer

### Phrase-by-phrase
- Phrase appears 30-50ms before first spoken word
- Fade-in: 150-200ms opacity 0 to 100%
- Exit: crossfade to next phrase (no blank frame)
- Never cut mid-sentence; breaks follow speech pauses

### Kinetic/Animated Pop
- Entry: Scale 0% → 120% in 80ms, ease to 100% in 40ms (120ms total bounce)
- Glow: activates 100ms after entry, peaks 200ms, stays for word duration
- Optional: +/-3 degree rotation on entry, returning to 0 by 150ms

## Color System for Finance Captions

| Color | Usage | Hex |
|-------|-------|-----|
| White | Neutral narration | #FFFFFF |
| Yellow/Gold | Positive keywords, wealth, emphasis | #f7c204 or #FFD700 |
| Red/Crimson | Negative concepts (debt, loss, crash) | #CC0000 |
| Green/Lime | Positive outcomes (growth, profit, returns) | #00FF88 |

## Font Recommendations

| Use Case | Font | Weight |
|----------|------|--------|
| Primary caption text | The Bold Font, Montserrat Bold, Archivo Black | Bold/Extra Bold |
| Numbers and data | Barlow Condensed, Bebas Neue | Bold |
| Labels and annotations | Poppins, Inter | Regular/Medium |
| Cartoon-matching | Nunito, Quicksand | Regular/SemiBold |
